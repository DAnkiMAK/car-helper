🚗 Помощник по подбору авто

Веб-приложение для подбора автомобилей с рынка Германии (AutoScout24). Пользователь задаёт параметры желаемого авто (марка, модель, бюджет, пробег, год и т.д.), а приложение отфильтровывает подходящие предложения и позволяет их сортировать.
    
Стек
  - Python 3.11+
  - pandas — работа с данными
  - Streamlit — веб-интерфейс
  - pytest — тестирование

Как запустить локально

  # 1. Создать и активировать виртуальное окружение
  python3 -m venv venv
  source venv/bin/activate
  
  # 2. Установить зависимости
  pip install -r requirements.txt
  
  # 3. Запустить приложение
  streamlit run app.py
  # откроется на http://localhost:8501
  
  # 4. (Отдельно) запустить тесты
  pytest

    Детальное описание функции "Рыночные ориентиры"

    Функция market_benchmarks(df, make, model=None) принимает очищенные данные
    и возвращает количество объявлений, медиану, квартили 25% и 75%, минимум
    и максимум цены. Если объявлений нет, возвращает None.
    Типичный диапазон — между квартилями 25% и 75%, а полный диапазон —
    между минимумом и максимумом. Квартили вычисляются стандартным методом
    pandas с линейной интерполяцией. При одной записи все границы равны её цене.
    В интерфейсе расчёт выполняется по всей выбранной марке/модели до применения
    бюджета и других фильтров: ограничение цены не должно искажать ориентиры.
    Если модель не выбрана, расчёт охватывает всю марку. При количестве
    объявлений меньше пяти показывается пояснение о небольшой выборке.
    Это описание цен объявлений в датасете, а не прогноз цены сделки.
    Тесты функции: tests/test_market_benchmarks.py.

    Детальное описание функции "Топ-5 предложений"

    Подборка строится после применения фильтров. Цена, пробег и год выпуска
    получают баллы от 0 до 1 относительно минимума и максимума в текущей выборке.
    Меньшая цена и пробег, а также более свежий год дают больше баллов.
    Баллы складываются с одинаковым весом. Если значение у всех машин одинаковое,
    этот параметр не влияет на порядок. При равенстве баллов сохраняется выбранная
    сортировка. Если найдено меньше пяти машин, показываются все найденные.

    Git-процесс для команды

    Правило: никто не пушит прямо в main. Каждый работает в своей ветке и сливает через Pull Request.

     1. Склонировать репозиторий:
         git clone https://github.com/DAnkiMAK/car-helper.git
         cd car-helper
     2. Настроить окружение и проверить, что всё работает:
         python3 -m venv venv && source venv/bin/activate
         pip install -r requirements.txt
         pytest          # должно быть все passed
     3. Создать свою ветку (например, для функции 3):
        git checkout -b feature/price-fairness
     4. Реализовать функцию в своём модуле core/ и написать тест в tests/.
     5. Запустить все тесты — должны проходить все (старые + новые):
         pytest
     6. Закоммитить и запушить ветку:
         git add .
         git commit -m "Добавлена функция 3: справедливость цены"
         git push -u origin feature/price-fairness
     7. На GitHub создать Pull Request из своей ветки в main. После проверки — слить.

    Как добавить свою функцию (шаблон)

     1. Создай модуль core/<имя>.py — чистые функции
     2. Создай tests/test_<имя>.py — используй фикстуру cars_df из conftest.py (не грузи весь датасет).
     3. Подключи результат в app.py, если это нужно интерфейсу.
     4. Прогони pytest — все тесты должны быть зелёными.
